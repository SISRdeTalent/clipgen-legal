GTAVI CLIP – Privacy Policy

Last updated: November 8, 2026

1. Data accessed

When a TikTok account authorizes GTAVI CLIP, the app receives an access token and the basic profile information allowed by the user.info.basic scope (open ID and display name), and permission to upload videos (video.upload, video.publish).

2. How data is used

This information is used only to confirm which account is connected and to upload videos to that account. It is not sold, shared with third parties, or used for advertising.

3. Storage

Access tokens are stored only on the developer's own computer, in a local file. No server or database collects user data.

4. Deletion

Access can be revoked at any time in the TikTok app (Settings and privacy → Security → Manage app permissions). Deleting the local token file removes all stored data.

Politique de confidentialité (FR)

GTAVI CLIP reçoit uniquement un jeton d'accès et les informations de profil de base (identifiant, pseudo) du compte TikTok qui l'autorise, afin de publier des vidéos sur ce compte. Aucune donnée n'est vendue, partagée ou utilisée à des fins publicitaires. Les jetons restent sur l'ordinateur du développeur. L'accès peut être révoqué à tout moment dans les paramètres TikTok.
